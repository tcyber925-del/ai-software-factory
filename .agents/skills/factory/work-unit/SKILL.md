# Work Unit Skill

Use the repository protocol in `docs/protocols.md` and schema in `schemas/work-unit.schema.json`.

## Rules
- Request capabilities, not named agents.
- Include explicit acceptance criteria.
- Keep scope bounded.
- Never silently change architecture or product requirements.
- Escalate ambiguity or conflicts.
